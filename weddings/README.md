# 婚礼

婚庆管理本质是以情感交付为导向的轻量级项目。尽管涉及更多“软性因素”（如审美、人际关系），但项目管理的方法论（目标管理、风险控制、资源协调）能显著提升筹备效率与成功率。实际应用中需结合柔性沟通与刚性流程，平衡标准化与个性化。


## 契合

（1）明确目标与范围

• 婚礼目标：在规定时间、预算内完成一场符合新人期待的仪式。

• 范围管理：需界定“婚礼包含什么”（如场地、婚纱、摄影）和“不包含什么”（如是否涵盖蜜月行程）。

（2）时间节点驱动

• 甘特图式进度表：婚庆流程需拆分任务（选场地、试妆、发请柬等），并严格对齐时间节点（如提前3个月预订酒店）。

• 里程碑事件：领证、试菜、婚礼彩排等关键节点需重点把控。

（3）资源与成本控制

• 预算分配：需平衡“刚性支出”（场地费）与“弹性支出”（装饰布置），并预留应急资金。

• 供应商管理：协调婚庆公司、摄影团队、餐饮等外部资源，类似项目管理中的“外包管理”。

（4）风险管理

• 预案设计：如雨天备用场地、设备故障应急方案、宾客突发缺席应对措施。

• 冲突协调：处理家庭意见分歧（如双方父母对流程的期待差异）。

## 特殊性

（1）强情感属性

• 需求优先级：需明确新人核心诉求（如“仪式感＞规模”或“亲友体验＞视觉效果”），类似项目中的“干系人管理”。

• 情绪管理：筹备压力可能引发新人焦虑，需通过沟通和进度透明化缓解。

（2）多角色协同复杂性

• 利益相关方：新人、双方家庭、伴郎伴娘、宾客等，需通过“RACI矩阵”明确责任分工（如谁负责确认菜单、谁通知亲友）。

• 沟通效率：避免信息不对称（如婚庆公司未同步流程改动给摄影团队）。

（3）临时性与唯一性

• 不可逆性：婚礼是“一次性项目”，试错成本极高（如流程错误无法重来）。

• 个性化交付：需根据新人偏好定制方案，类似“敏捷项目管理”中的迭代调整。

## 方法

• 工具适配：

  ◦ 用 Trello/Excel 跟踪任务进度，Notion 整合合同、预算表、宾客名单。

  ◦ 关键路径法（CPM） 识别最长任务链（如“订酒店→发请柬→确认人数”）。

• 方法论适配：

  ◦ 采用 WBS（工作分解结构） 拆解任务（示例：一级任务“场地筹备”→二级任务“签合同、布置、设备调试”）。

  ◦ 通过 PDCA循环（计划-执行-检查-改进）持续优化细节（如彩排后调整流程顺序）。
